# Golden Sunday Portfolio

A lightweight, honest portfolio built with HTML, Tailwind CSS via CDN, and vanilla JavaScript.

## Structure

- `index.html`, `about.html`, `projects.html`, `services.html`, `collaboration.html`, `contact.html`
- `assets/styles/site.css`
- `scripts/main.js`
- `scripts/contact.js`

Project content is intentionally limited to the existing GreenCourt Homes learning project. Replace placeholders and add real links as work becomes available.
